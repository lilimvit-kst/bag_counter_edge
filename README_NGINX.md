# 🚀 Bag Counter Edge - Обновленная конфигурация с Nginx

## ✅ Решение проблемы с видеопотоком

Добавлен **Nginx reverse proxy** для унифицированного доступа ко всем сервисам через один порт.

### Что изменилось:

1. **Nginx Proxy** - новый сервис, который маршрутизирует запросы:
   - `/` → Dashboard (порт 8501)
   - `/api/` → Edge-CV API (порт 8000)
   - WebSocket подключения автоматически поддерживаются

2. **Dashboard** теперь использует `NGINX_PROXY=true` и обращается к API через `localhost:80`

3. **Порт доступа**: теперь дашборд доступен по адресу `http://<IP-сервера>:80` (стандартный HTTP порт)

### Инструкция по запуску:

```bash
# Остановить текущие контейнеры
docker compose down

# Запустить обновленную конфигурацию
docker compose up -d --build

# Проверить статус
docker compose ps

# Посмотреть логи nginx (если есть проблемы)
docker compose logs nginx
```

### Доступ к системе:

- **Дашборд**: `http://<IP-вашего-сервера>/` или `http://<IP-вашего-сервера>:80/`
- **API напрямую**: `http://<IP-вашего-сервера>:8000/`
- **WebSocket**: `ws://<IP-вашего-сервера>:8765/`

### Преимущества нового подхода:

✅ **Единая точка входа** - все запросы через порт 80  
✅ **Нет проблем с DNS** - dashboard обращается к localhost  
✅ **WebSocket поддержка** - видеопоток работает стабильно  
✅ **Безопасность** - можно легко добавить SSL/TLS через nginx  
✅ **Масштабируемость** - легко добавить балансировку нагрузки  

### Открытие порта в фаерволе:

```bash
# Для UFW
sudo ufw allow 80/tcp

# Для firewalld
sudo firewall-cmd --add-port=80/tcp --permanent && sudo firewall-cmd --reload
```

### Проверка работы:

1. Откройте браузер и перейдите на `http://<IP-сервера>/`
2. Включите "Live Camera Feed" в sidebar
3. Видеопоток должен отображаться без ошибок

### Откат к старой конфигурации (без nginx):

Если нужно вернуться к прямой схеме подключения:

```bash
# В docker-compose.yml удалите секцию nginx
# У dashboard добавьте порт: - "8501:8501"
# Удалите переменную NGINX_PROXY=true из environment dashboard
# Перезапустите: docker compose up -d --force-recreate dashboard
```
